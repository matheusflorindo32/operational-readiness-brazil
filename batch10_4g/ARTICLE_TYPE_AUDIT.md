# Article-type audit

## Determination

The defensible label is **evidence-informed integrative synthesis with an explicit evidence-governance framework**. It is not a systematic review, PRISMA-compliant review, clinical guideline, validated model, or consensus statement.

## Basis

The project contains staged searching, screening and full-text appraisal, but the reconstruction blueprint draws only from already versioned, result-located evidence. Access limitations, unadjudicated contradictory records and human review pending status preclude claims of systematic-review completeness.

## Required labels

- `PROPOSED SYNTHESIS FRAMEWORK — NOT YET VALIDATED`
- AI-provisional evidence appraisal; human confirmation pending.
